How to install

Debian
  1. Download the script above (my-voice-setup.sh).
  2. Open a terminal and run bash ~/Downloads/my-voice-setup.sh as your normal user. It asks for your password once to install two packages.
  3. In your sound settings, or in the app you're using, pick the input Server mic (my-voice).
  4. That's it - it starts by itself when you log in, and Arty's replies play through this PC.

To remove it: bash ~/Downloads/my-voice-setup.sh --uninstall. Log: ~/.local/share/my-voice/my-voice.log

Windows
  1. Install VB-CABLE (free): unzip it, right-click VBCABLE_Setup_x64.exe → Run as administrator → Install Driver, then restart. This gives Windows the extra microphone.
  2. Download the script above (my-voice-setup.ps1).
  3. Open PowerShell and run powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\my-voice-setup.ps1". It installs Python for your user if you don't have it.
  4. In Windows sound settings, or in the app you're using, pick the microphone CABLE Output (VB-Audio Virtual Cable).
  5. That's it - it starts with Windows, and Arty's replies play through your default speakers.

To remove it: run the same command with -Uninstall on the end. Log: %LOCALAPPDATA%\my-voice\my-voice.log
